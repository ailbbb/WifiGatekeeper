# Wi-Fi Gatekeeper — حارس الشبكة المنزلية 🔐

تطبيق أندرويد يحوّل راوتر منزلك إلى شبكة **قائمة بيضاء فقط (Whitelist-only)**: أي جهاز جديد يحاول الاتصال بالواي فاي يُظهر **إشعاراً فورياً على هاتفك بأزرار قبول / رفض** — عند القبول يُضاف الجهاز تلقائياً إلى قائمة تصفية MAC في الراوتر، وعند الرفض يبقى محجوباً. لا مزيد من الغرباء على شبكتك.

| | |
|---|---|
| **الإصدار** | v1.5.0 (versionCode 6) — تدقيق هندسي شامل وتأمين الحماية الذاتية |
| **يتطلب** | أندرويد 8.0 فما فوق |
| **اختبارات الوحدة** | 45/45 ✓ |
| **الراوترات المدعومة** | TP-Link Classic + TP-Link New (WlanMacFilterRpm) + Generic — كشف تلقائي |

## ✨ الميزات

- **🛡 تأمين الحماية الذاتية (v1.5.0 — الأهم)**: تعرّف التطبيق على MAC هاتفك الآن من **جدول الراوتر نفسه** (مطابقة IP) بدل قراءة عنوان الجهاز من النظام — لأن أندرويد 10+ يستخدم MAC عشوائياً للواي فاي، فالطريقة القديمة كانت قد تُدرج عنواناً خاطئاً ثم تشغّل الفلتر وتُسقط الهاتف من الشبكة. إذا لم يُؤكد الراوتر العنوان: **يظل الفلتر مطفأً** ويطلب التطبيق منك اختيار هاتفك من قائمة الأجهزة المتصلة (أو كتابة MAC يدوياً) — لا قفل أبداً.
- **📡 ربط الطلبات بشبكة الواي فاي (v1.5.0)**: مع تفعيل بيانات الجوال والواي فاي معاً، كان أندرويد قد يوجّه طلبات الراوتر عبر 4G (فشل «تعذر الوصول للراوتر»). كل طلبات الراوتر الآن مثبتة على قناة الواي فاي إلزامياً.
- **🔔 لا انهيار مع صلاحيات الإشعارات (v1.5.0)**: على أندرويد 13+ كان أول جهاز جديد يُسقط حلقة المراقبة بـ SecurityException إن كانت صلاحية الإشعارات مقفلة — مُصلح، واللافتة الصفراء تختفي فور منح الصلاحية.
- **🧰 إصلاحات v1.4.0**: المتصفح (زر الرجوع + التقاط تسجيل الدخول بجافاسكربت)، راوترات كلمة السر الفارغة، إشعار فشل صريح لزر «قبول»، وزر Clear يعمل.
- **🛡 حماية بضغطة واحدة (v1.3.0)**: يضيف هاتفك إلى القائمة البيضاء **أولاً**، ثم يشغل فلترة MAC، ثم يبدأ المراقبة الحية — مع تحقق مزدوج (إعادة قراءة القائمة البيضاء من الراوتر قبل تشغيل الفلتر).
- **⚡ الربط السريع بالمتصفح (v1.2.0) — الأسهل**: صفحة الراوتر الحقيقية داخل متصفح مدمج؛ سجّل الدخول كالمعتاد والتطبيق يقرأ بيانات الدخول ويكتشف نوع الراوتر وحده، ويحرر جلسة المتصفح قبل استلام العميل الأصلي (حماية من قفل الجلسة الواحدة). المتصفح مقصور على الشبكة المحلية فقط.
- **إشعارات فورية تفاعلية** — أزرار «قبول» و«رفض» من شريط الإشعارات؛ الإشعار يفشل بصوت مسموع (بالسبب) إن رفض الراوتر.
- **دعم TP-Link Classic + TP-Link New** — الجيل القديم `WlanAccessRpm` والأحدث `WlanMacFilterRpm`، مع ترويسة `Referer` إلزامية على كل طلب (فيرموير TP-Link يرفض غيرها) وقوائم MAC بصيغتي النقطتين والشرطة.
- **مراقبة حية + عمل مستمر** — خدمة أمامية نوع `dataSync` مع احتياطي WorkManager كل 15 دقيقة، إعادة تشغيل بعد الإقلاع، وانهيار Keystore المشفّر يُسترد تلقائياً بدل انهيار التطبيق.
- **بيانات محمية** — بيانات اعتماد الراوتر مشفّرة (Keystore)، `network_security_config` يضمن سماح HTTP المحلي، وقاعدة بيانات Room وإعدادات DataStore.

> **لماذا لا يوجد زر WPS؟** نظام أندرويد أزال دعم WPS من التطبيقات منذ الإصدار 9، فلا يمكن لأي تطبيق حديث الضغط على زر الراوتر أو قراءة رمزه — الربط السريع بالمتصفح أعلاه هو البديل العملي والآمن. كما يصلح v1.2.0 مشكلة كان قد يحجب فيها أندرويد اتصال التطبيق بـ `http://` للراوتر على بعض الأجهزة.

## 🛠 البناء من المصدر

```bash
./gradlew :app:assembleDebug
# الناتج: app/build/outputs/apk/debug/app-debug.apk
```

المتطلبات: JDK 17 و Android SDK بمنصة 35 (عبر `ANDROID_HOME` أو `local.properties`).
اختبارات الوحدة: `./gradlew :app:testDebugUnitTest`.

## 📐 بنية الكود

```
app/src/main/java/com/wifigatekeeper/
  core/router/     عملاء الراوتر (Classic، New، Generic)، كاشف النوع، المحلل، مطبّق الحماية، التحقق
  core/network/    فحوصات الشبكة/البوابة + حارس عناوين LAN + محدد MAC الهاتف
  data/            Room DB، بيانات اعتماد مشفرة، إعدادات DataStore، المستودع
  notifications/   قنوات الإشعارات، التنبيهات التفاعلية، مستقبل الأزرار
  background/      خدمة المراقبة الأمامية، WorkManager، مستقبل الإقلاع
  ui/              شاشات Compose (الإعداد + معالج الحماية + الربط السريع + لوحة التحكم)
```
