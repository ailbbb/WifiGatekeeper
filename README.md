# Wi-Fi Gatekeeper — حارس الشبكة المنزلية 🔐

تطبيق أندرويد يحوّل راوتر منزلك إلى شبكة **قائمة بيضاء فقط (Whitelist-only)**: أي جهاز جديد يحاول الاتصال بالواي فاي يُظهر **إشعاراً فورياً على هاتفك بأزرار قبول / رفض** — عند القبول يُضاف الجهاز تلقائياً إلى قائمة تصفية MAC في الراوتر، وعند الرفض يبقى محجوباً. لا مزيد من الغرباء على شبكتك.

|---|---|

## ✨ الميزات

- **🧰 v1.4.0 — إصلاح شامل**: المتصفح (زر الرجوع يعمل داخله بدل إغلاق التطبيق + التقاط تسجيل الدخول بجافاسكربت بدون submit)، راوترات كلمة السر الفارغة (شائعة عند مزودي الإنترنت مثل راوترات الاختبار)، إشعار فشل صريح عند رفض الراوتر لزر «قبول»، وزر Clear في سجل النشاط يعمل فعلياً.
- **🛡 حماية بضغطة واحدة (v1.3.0)**: فور نجاح تسجيل الدخول عبر الربط السريع — أو من زر «Protect this phone now» في الإعدادات — يحدد التطبيق هاتفك تلقائياً (MAC)، يضيفه إلى القائمة البيضاء **أولاً**، ثم يشغل فلترة MAC، ثم يبدأ المراقبة الحية. الترتيب مقصود: لا يمكنك أبداً قفل نفسك خارج الشبكة.
- **⚡ الربط السريع بالمتصفح (v1.2.0) — الأسهل**: شاشة الإعداد تفتح صفحة الراوتر الحقيقية داخل متصفح مدمج؛ سجّل الدخول كالمعتاد والتطبيق يقرأ بيانات الدخول تلقائياً، يتحقق منها، ويكتشف نوع الراوتر وحده — لا كتابة يدوية ولا اختيار نوع. المتصفح مقصور على عناوين الشبكة المحلية فقط (حماية من التصيد)، والبيانات تبقى مشفرة على هاتفك.
- **إشعارات فورية تفاعلية** — أزرار «قبول» و«رفض» مباشرة من شريط الإشعارات لأي جهاز جديد يحاول الاتصال. **جديد v1.3.0**: طلب صلاحية الإشعارات تلقائياً على أندرويد 13+ ولافتة تحذير إن كانت مقفلة (كان هذا سبب اختفاء الإشعارات).
- **قائمة بيضاء (Whitelist)** — الأجهزة المسموحة فقط تدخل الشبكة؛ القبول يضيف الجهاز لقائمة MAC filtering في الراوتر آلياً.
- **دعم TP-Link Classic + TP-Link New (جديد v1.3.0)** — راوترات WR940N / WR841N بأجيالها: الجيل القديم بصفحات `WlanAccessRpm` والجيل الأحدث (v6+) بصفحات `WlanMacFilterRpm` وتحديثات GET — هذا الإضافة تصلح خطأ **HTTP 500** عند تشغيل الفلتر على الأجيال الأحدث.
- **اكتشاف تلقائي للبوابة والنوع** — يحدد عنوان راوترك ونوع واجهته بنفسه؛ الافتراضي `192.168.0.1` لإصدارات TP-Link الكلاسيكية.
- **مراقبة حية** — لوحة تحكم (Jetpack Compose) تعرض الأجهزة المتصلة حالياً وحالة الشبكة.
- **عمل مستمر** — خدمة أمامية (Foreground Service) مع احتياطي WorkManager، وإعادة تشغيل تلقائية بعد إقلاع الهاتف.
- **بيانات محمية** — بيانات اعتماد الراوتر مشفّرة، وقاعدة بيانات Room وإعدادات DataStore.
- **أيقونة وواجهة جديدة** — تصميم محدث للشاشة الأولى ولأيقونة التطبيق.

> **لماذا لا يوجد زر WPS؟** نظام أندرويد أزال دعم WPS من التطبيقات منذ الإصدار 9، فلا يمكن لأي تطبيق حديث الضغط على زر الراوتر أو قراءة رمزه — الربط السريع بالمتصفح أعلاه هو البديل العملي والآمن. كما يصلح v1.2.0 مشكلة كان قد يحجب فيها أندرويد اتصال التطبيق بـ `http://` للراوتر على بعض الأجهزة.

## 🛠 البناء من المصدر

```bash
./gradlew :app:assembleDebug
# الناتج: app/build/outputs/apk/debug/app-debug.apk
```

المتطلبات: JDK 17 و Android SDK بمنصة 35 (عبر `ANDROID_HOME` أو `local.properties`).
اختبارات الوحدة: `./gradlew :app:testDebugUnitTest`.

## 📐 بنية الكود

```
app/src/main/java/com/wifigatekeeper/
  core/router/     عملاء الراوتر (Classic، New، Generic)، كاشف النوع، المحلل، مطبّق الحماية، التحقق
  core/network/    فحوصات الشبكة/البوابة + حارس عناوين LAN + محدد MAC الهاتف
  data/            Room DB، بيانات اعتماد مشفرة، إعدادات DataStore، المستودع
  notifications/   قنوات الإشعارات، التنبيهات التفاعلية، مستقبل الأزرار
  background/      خدمة المراقبة الأمامية، WorkManager، مستقبل الإقلاع
  ui/              شاشات Compose (الإعداد + معالج الحماية + الربط السريع + لوحة التحكم)
```
